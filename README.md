# pwdlc_r3_u2
Programación WEB del lado del Cliente

Reto 3 Crear un formulario HTML y aplicar estilos usando CSS

Este Reto tiene el propósito de profundizar en los conceptos básicos del uso de formularios empleando HTML y
CSS. Explora las posibilidades y combina colores y tipografías para obtener un diseño que sea tanto funcional
como visualmente atractivo.

INSTRUCCIONES

Desarrollo del Formulario

Crea un archivo HTML que contenga un formulario con los siguientes elementos:

    ● Un título que diga "Registro de la persona Usuaria".
 
    ● Campos de texto para: Nombre, Apellido, Correo Electrónico y Contraseña.
 
    ● Un área de texto (textarea) para que las personas usuarias puedan introducir una breve descripción
      sobre sí mismas.
   
    ● Un conjunto de opciones (checkboxes) que indiquen sus intereses (ejemplo: "Tecnología", "Arte",
      "Deporte").
   
    ● Un botón de envío (submit) con el texto "Registrarse".
 
    ● Usa la etiqueta label para cada campo del formulario para identificar su propósito.

Estilización

Aplica estilos a tu formulario utilizando CSS. 

Usa los siguientes conceptos:

    ● Selectores de id, clase y elemento.
    
    ● Fuentes: tamaños, tipografías y colores de texto.

    ● Bordes para campos, botones y área de texto.
    
    ● Backgrounds: colores de fondo para diferentes secciones o elementos del formulario.
